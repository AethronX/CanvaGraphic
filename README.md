# Portfolio — ملف أعمال مصمّم جرافيك

ملف أعمال احترافي من 14 صفحة (A4 أفقي، 297×210mm) مبني بالكامل كرسوم متجهة — لا صور مستوردة ولا علامات مائية.

## الملفات
- `Portfolio-Graphic-Designer-AR.pdf` — الملف النهائي للإرسال
- `portfolio.html` — المصدر القابل للتعديل
- `assets/fonts/` — Reem Kufi · Readex Pro · Amiri · Inter (رخصة OFL)
- `assets/art/` — الزخرفة الهندسية والنجمة السداسية عشرية (مولّدة رياضياً) + ملمس الحبيبات

## إعادة التصدير بعد أي تعديل
```bash
chromium --headless --no-pdf-header-footer --virtual-time-budget=10000 \
  --print-to-pdf=Portfolio-Graphic-Designer-AR.pdf portfolio.html
```

## قبل الإرسال لأي عميل
1. استبدل الحقول بين `[ ]` (الاسم، الجوال، البريد، بيهانس، إنستغرام) — صفحتا 1 و14.
2. استبدل أسماء المشاريع والأرقام بأعمالك ونتائجك الحقيقية.
3. استبدل الرسوم المتجهة بصور مشاريعك عند توفّرها (`<img>` داخل نفس الحاويات).
